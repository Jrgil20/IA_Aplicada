El buscador para el agente

Decisión de arquitectura para TI Problema 10 · 05/11/2026 11:56

Recomendación para TI

Adoptar el buscador MCP como única vía de acceso del agente a documentos/. Reduce el contexto documental en 90 % y mantiene 12 de 12 respuestas correctas.

El ahorro de contexto es la diferencia decisiva: el modo directo vuelca archivos completos y deja menos espacio para el razonamiento; el buscador entrega solo los fragmentos pertinentes, con documento y sección, y permite auditar qué ve el modelo. La condición de TI se cumple porque el agente MCP no puede abrir, listar ni buscar dentro de documentos/: solo recibe lo que devuelve el servidor.

Condición de TI verificada: el agente MCP no abre archivos de documentos/
Ahorro de contexto 90 % 24.437 → 2.377 caracteres por pregunta
Acierto con MCP 100 % 12 de 12 · modo directo 100 %
Latencia promedio 2.9 s MCP 44 % más rápida que el modo directo
Contexto estimado 1.262 tokens con MCP vs 6.777 en directo

A

El agente llama buscar_documentos y recibe los 5 fragmentos más pertinentes, con cita de documento y sección. No abre archivos.

Condición de TI y alcance

Qué ve el agente en cada modo

  • Modo A: puede listar, buscar y abrir cualquier archivo de documentos/. El contexto depende de cuántos archivos abra.
  • Modo B: solo recibe los fragmentos que devuelve buscar_documentos y las secciones que pida con leer_fragmento.
  • En ambos modos se usó el mismo modelo local, el mismo prompt de sistema y los mismos criterios de corrección de Legal.

Configuración que hace cumplir la condición

El agente agente-mcp tiene denegado read, glob y grep sobre documentos/**, además de shell. El servidor está registrado en opencode.json.

{
  "mcp": { "servers": { "buscador": {
    "type": "local",
    "command": ["python3", "asistente/servidor_mcp.py"]
  }}},
  "agents": { "agente-mcp": { "permissions": [
    { "action": "read", "resource": "documentos/**", "effect": "deny" },
    { "action": "glob", "resource": "documentos/**", "effect": "deny" },
    { "action": "grep", "resource": "documentos/**", "effect": "deny" },
    { "action": "shell", "resource": "*", "effect": "deny" }
  ] }}
